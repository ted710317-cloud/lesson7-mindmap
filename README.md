# 國語第七課《跟著公共藝術去旅行》心智圖關鍵字排序互動學習網

專為國小六年級國語科設計的心智圖關鍵字排序互動練習網頁，支援電腦與平板（iPad/Chromebook）觸控操作。

## 🌟 線上體驗網址（GitHub Pages）
- **線上互動練習**：[點此立即開始練習](https://ted710317-cloud.github.io/lesson7-mindmap/)

---

## 🎯 功能特色
1. **結構鷹架引導**：保留課文核心主題與一級分支（起因、經過（一）花間小鹿、經過（二）分合隨緣、經過（三）參觀美術館、結果—爸媽的說明、迴響）。
2. **多模式互動操作**：
   - **電腦端**：支援流暢拖曳（Drag & Drop）放置關鍵詞卡片。
   - **平板端**：支援觸控「點選卡片 ➔ 點選框格」快速放置，點擊已填格位即可收回詞庫。
3. **音效與自動計分**：內建 Web Audio API 音效，點擊「🔍 檢查答案」自動評分，綠色正確、紅色訂正。
4. **一鍵匯出 PDF**：輸入學生班級、座號、姓名，點擊「📥 下載心智圖 (PDF)」自動產出高解析度 A4 橫向 PDF 學習成果報告。
5. **Padlet 沙盒支援**：內附 2560×1440 高畫質底圖 `lesson7_sandbox_scaffold.png`，可直接匯入 Padlet Sandbox 作為課堂活動畫布。
